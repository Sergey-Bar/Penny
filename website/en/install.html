Download

Download and install.

Pick your system and follow the steps in order. Windows and Mac need no terminal.

Before you start

  • A computer

    Windows 10 or 11, macOS 13 or newer, or Linux with Docker.

  • A browser

    Chrome or Edge installed. Bank sync uses it.

  • Your bank account

    Automatic sync needs two-factor sign-in turned off on the bank's website (One Zero is the exception). Without that, import statement files.

Windows 10 and 11

Download for Windows
  1. Download Penny-Setup-0.5.0.exe (169 MB). You don't need Node.js or anything else.
  2. Install: run the file. If SmartScreen warns about an unsigned app, choose More info, then Run anyway.
  3. Run: open Penny. The first time, a short onboarding walks you through it: a profile, a bank or a file, a monthly target and budgets.

Good to know

Bank sync uses the Chrome or Edge you already have. Your data is kept in %APPDATA%\Penny\data.

Updating

Penny downloads the update itself and asks to restart. Your data stays.

macOS 13 and newer

Apple silicon (M1 and newer)Intel
  1. Download the .dmg that matches your processor. Not sure? About This Mac in the Apple menu names the chip.
  2. Install: open the file and drag Penny to Applications.
  3. Run: on first open, macOS blocks an unsigned app. Go to System Settings, Privacy & Security and choose Open Anyway. Then a short onboarding walks you through it: a profile, a bank or a file, a monthly target and budgets.

If macOS says the app is damaged

Run this in Terminal and open Penny again:

xattr -cr /Applications/Penny.app

Good to know

Bank sync uses the Chrome or Edge you already have. Your data is kept in ~/Library/Application Support/Penny/data.

Updating

When a new version is out, Penny shows a banner. Run the new installer over the old one, and your data stays.

Docker

Penny, its scrapers and Chromium in a container, isolated from your machine. Suits Linux, a home server or a NAS, and works on Windows and Mac too.

  1. Run one command in a terminal:

    Mac and Linux

    curl -fsSL https://raw.githubusercontent.com/Sergey-Bar/Penny/main/install-docker.sh | bash

    Windows (PowerShell)

    irm https://raw.githubusercontent.com/Sergey-Bar/Penny/main/install-docker.ps1 | iex
  2. The installer does the rest: it checks that Docker is installed and running (on Windows and Mac it offers to install Docker Desktop), downloads the newest release into ~/Penny, builds and starts it.
  3. Run: it opens http://127.0.0.1:41234 when it's ready. Bookmark it.

Good to know

The database and the encryption key live in the penny-data volume and survive updates. Drop statement files to import into the imports folder.

Updating

Run the same command again. If a newer release exists it offers to update: it backs up your data and key first, builds and checks the new version, and rolls back if it isn't healthy.

From source

For developers, or if you want an always-on service. Needs Node.js 22 or newer.

  1. Download and install: 
    git clone https://github.com/Sergey-Bar/Penny.git
cd Penny && npm install
npm run setup
  2. Setup builds the app and installs a service that starts with your computer. On Windows it asks for Administrator once, to add the penny.localhost address.
  3. Run: open http://penny.localhost:41234 and bookmark it.

Updating

Run git pull, then npm run service:reload.

Uninstalling

npm run uninstall removes the service. The data folder, with your data and encryption key, is kept.

And after installing?

  • Connect your accounts

    A bank or credit card with automatic sync, open banking, or an Excel or CSV file. You can mix them, and the history comes in together.

  • Set a lock

    A password or a PIN. While the app is locked, the encryption key isn't on disk without them.

  • Set up backup

    An automatic encrypted backup to a folder that Google Drive, OneDrive, Dropbox or iCloud syncs. It opens only with your password.

  • Connect the Telegram bot

    With a one-time code from Settings. From then on, summaries, reminders and alerts arrive in your chat.

A personal tool for your own accounts only. Automated access to banks may violate their terms of service. Calculators give estimates, not advice.

Something not working?

The most common problems are here. For the rest there is a full guide, and you can open an issue on GitHub.

Windows warns that the app is unrecognised

The installer isn't signed, so SmartScreen warns the first time. Choose More info, then Run anyway. Updates themselves are signed and checked before they install.

macOS says the app is damaged, or won't open it

Go to System Settings, Privacy & Security and choose Open Anyway. If it says the app is damaged, run xattr -cr /Applications/Penny.app in Terminal and open it again.

A bank sync fails with a Cloudflare page

Import that month's statement file instead. On a source or Docker install you can also try the setting PENNY_DISABLE_CHROMIUM_SANDBOX=1.

Docker: it says Docker is not running

Start Docker Desktop and run the command again. On Linux: sudo systemctl start docker, and make sure your user is in the docker group.

Port 41234 is in use

Another program is using it. Find it with netstat -ano | findstr :41234 on Windows or lsof -nP -iTCP:41234 -sTCP:LISTEN on Mac and Linux, stop it and start again.

penny.localhost doesn't open on Windows

Use http://127.0.0.1:41234, which always works, or run setup again from an Administrator terminal.

Something looks stale after an update

Hard-refresh the page with Ctrl+F5.
