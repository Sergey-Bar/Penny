Guides/Import your pension report

How to import your agent's pension report and check your fees.

The periodic report your agent or advisor sends holds all your long-term savings in one place. One import brings it into Penny, and from there you see what each product is worth and what you pay for it.

01

Get the periodic report

Ask your insurance agent or advisor for the periodic report: pension, study fund, provident fund and the insurance in them. This is not the pension clearing-house report, which Penny doesn't read yet.

02

Turn it into JSON

Penny doesn't read the PDF itself. The data has to be extracted into a JSON file shaped like the example file. Any tool that produces that shape works. The full format.

  • The report date, as YYYY-MM-DD
  • Total savings, from the report's own summary
  • For each product: type, name, provider and balance
  • Optionally: management fees, the monthly deposit and the insurance in the report
03

Import the file

Under Settings → Accounts & import, in the group Pension, study funds and investment houses, find Import a pension report. There is a link to an Example file there. Press Choose a JSON file and pick your file.

04

Check what came in

When it finishes it tells you how many products and policies were imported. Each product lands in assets with its value on the report date, its management fees and its monthly deposit. Each policy lands in insurance, with a monthly premium.

05

Check your fees against the market

Money on the table lists management fees that are above what is usual in the market, with the yearly amount and the next step. Once you've dealt with one, press Done it and the saving counts.

06

Refresh when a new report arrives

Import the new report the same way. A product that already exists is updated, not duplicated, and what you changed yourself, such as an asset's name or the notes on a policy, is kept.

Good to know

  • The import is checked against the report's own summary: if the products don't add up to the total savings, the file is refused and nothing is imported.
  • Reading the pension clearing-house report automatically is still on the roadmap. For now the calculators include a guide to reading it.
  • The comparison with the market is an estimate, not pension advice.
  • The file is read and stored on your computer, and none of it leaves.

Questions and answers

My provider syncs directly. Do I still need the report?

You don't have to. Meitav, Altshuler Shaham, Phoenix, Excellence Trade, Harel, Migdal, Clal and Menora connect directly and update your balances. The report adds fees, deposits and insurance. More on pension and savings.

The import failed. What do I check?

That the file is valid JSON, that it matches the example file, and that the products' balances add up to the total savings in the summary.

What if I import the same report twice?

It is updated, not duplicated. The same report is recognised by its date, member and source.
